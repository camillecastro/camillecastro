Python | NumPy | SciPy | Signal Processing

View Project

An exploratory software project connected to my Computer Engineering Senior Design work, focused on developing an adaptable wearable electrode and sensor interface for post-stroke rehabilitation.

# ⚙️ PID Control Systems Simulator

Python | NumPy | Matplotlib | Control Theory

An educational simulation exploring proportional, proportional-integral, and proportional-integral-derivative feedback controllers.

The project investigates transient response, overshoot, settling time, steady-state error, and controller performance.
